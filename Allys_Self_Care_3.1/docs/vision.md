# Healthy Habits for Adventurous Lives

## Vision

Build a wellbeing companion that helps adventurous people become stronger, healthier and more consistent through small daily habits.

## Principles

- Simple beats complicated.
- Encourage, never shame.
- Celebrate progress.
- Build habits for life.
- Support adventure, not perfection.

## Success

A user opens the app every day because it helps them make one good decision.
