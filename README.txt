ALLY'S SELF CARE 2.0 - ALPHA 1

Healthy habits for adventurous lives.

ACTION FOR ALLY

1. Download and extract this ZIP file.
2. Open the extracted Allys_Self_Care_Alpha_1 folder.
3. Copy ALL files and folders inside it.
4. Paste them into your local GitHub folder named ally-self-care.
5. If Windows asks whether to replace files, choose Replace.
6. Open GitHub Desktop.
7. In the Summary box, type:
   Alpha 1
8. Click Commit to main.
9. Click Push origin.
10. Wait around 30 to 60 seconds, then open:
    https://ally-self-care.vercel.app

ALPHA 1 INCLUDES

- One shared selected-date engine
- Monday-to-Sunday weekly step calculations
- Daily steps stored against the correct date
- Live Insights that refresh after each save
- Daily check-in
- Sleep in hours and minutes
- Water in millilitres
- Nutrition entry and editable targets
- Weekly nutrition summary
- Wins This Week
- Dark mode
- Data migration from earlier local versions where the browser can see them
- Backup export and import
- Progressive Web App groundwork

IMPORTANT

Because the previous prototype files were opened as local chat downloads, their browser storage may not be visible to the new Vercel address. Export a backup from the old app before relying on migration. Alpha 1 has an Import Backup button under Goals.
