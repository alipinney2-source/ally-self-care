# Coding Standards

## Principles

- Keep files small.
- One responsibility per file.
- Test before committing.
- Never break main.
- Write code that future Ally can understand.
- Every change should make the app easier to understand.
## Workflow

- Create a branch for significant changes.
- Test before committing.
- Keep commit messages clear and descriptive.
- Merge into `main` only after testing.
